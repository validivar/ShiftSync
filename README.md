## ✅ Key Features

### 🗓️ Scheduling & Roster Generation
- One-click intelligent roster generation
- Mathematically optimised for fairness and compliance
- Infinite calendar support (from 1960 to any future date)
- Automatic shift pattern detection and time pre-filling

### 👥 Staff Management
- Add unlimited staff members with rank, employment type, and shift preferences
- Skills and certifications tracking for skill-matched assignments
- Bulk CSV staff import (FirstName, LastName, Rank, EmploymentType, Skills)
- Undo last action for accidental changes

### 📋 Leave & Availability Management
- Sick Leave, Annual Leave, Maternity/Paternity, Study Leave, Approved Absence
- Date-range leave entries automatically reflected in generated rosters
- Leave type codes displayed in roster cells

### 🔄 Shift Operations
- **Open Shifts** — post, assign, and manage uncovered shifts
- **Shift Swap Requests** — submit, approve, and deny swap requests
- Multi-site and multi-location roster support

### ⚖️ Compliance & Wellbeing
- Minimum and maximum weekly hours enforcement
- **Fatigue Management** — max consecutive shifts + minimum rest hours
- EU Working Time Directive aligned defaults (11-hour rest minimum)
- Compliance pass/fail indicator on every generated roster

### 📊 Export & Sharing
- Export to professionally formatted **PDF** (via jsPDF)
- Export to **Excel/XLSX** (via SheetJS)
- **Print** directly from browser
- **Save** roster to browser localStorage
- **Share** via Web Share API or clipboard link

### 🌍 Accessibility & Language
- **50+ languages** via Google Translate
- Fully **responsive** — works on desktop, tablet, and mobile
- **Dark mode** with localStorage persistence
- Works fully **offline** after first load

### 🔒 Privacy
- All data stored in **browser localStorage only**
- **Zero data transmission** to any server
- No cookies for scheduling data
- No account, no email, no tracking of your workforce data

## 🚀 How to Use ShiftSync

ShiftSync requires **no installation, no account, and no configuration**. Just visit
[www.shiftsync.world](https://www.shiftsync.world) and:

```
Step 1 → Select your industry and enter organisation details
Step 2 → Choose a shift pattern (Panama, Dupont, 4x4, etc.)
Step 3 → Add staff members (or import from CSV)
Step 4 → Set leave dates for any staff members if needed
Step 5 → Click "Generate Intelligent Roster"
Step 6 → Export to PDF or Excel, or print directly
```

**Total time from opening the app to downloading a roster: under 3 minutes.**

## 🚀 Deployment

### Option 1 — Deploy to GitHub Pages (Free)
```bash
# 1. Fork or clone this repository
git clone https://github.com/yourusername/shiftsync.git

# 2. Push to your GitHub account
git push origin main

# 3. Go to Settings → Pages → Source: main branch, / (root)
# 4. Your site goes live at: https://yourusername.github.io/shiftsync
```

### Option 2 — Deploy to Custom Domain (Recommended)
```bash
# 1. Upload all files to your hosting provider via FTP or File Manager
# 2. Point your domain DNS to your host
# 3. Enable HTTPS/SSL (free via Let's Encrypt on most hosts)
# Recommended host: https://hostinger.com?REFERRALCODE=WENIKPOMAK80
```

### Option 3 — Deploy to Netlify (Free, Fastest)
